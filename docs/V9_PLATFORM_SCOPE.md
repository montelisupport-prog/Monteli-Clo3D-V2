# V9 Complete Platform Scope

V9 consolidates the complete target architecture rather than adding isolated feature requests.

Active foundations: professional pattern geometry operations, grading rules, sewing relationships, knit material models, measured fabric calibration, avatar/pose model, fit metrics, construction/trims/artwork systems, marker consumption, BOM/costing, project revisions, sample tracking, AI-controlled alterations, Garment DNA, production validation/export.

Validation-gated: full WebGPU XPBD constraints and continuous collision/self-collision, arbitrary inverse cloth solving, certified AAMA/ASTM interoperability, and photoreal fiber/HDR rendering. These require benchmark suites, external format validation, and/or substantially deeper native/GPU engineering. The UI identifies these explicitly rather than representing them as production-equivalent.
