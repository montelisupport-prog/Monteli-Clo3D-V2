# V10 Visual CAD

The Pattern step is now a working visual workspace rather than a navigation-only step.

- Finished flat-lay measurements in cm generate visible Front, Back and Sleeve cut pieces.
- Measurements in the right inspector redraw the pieces.
- White anchors can be dragged directly.
- Gray Bézier handles can be dragged like a curve editor.
- Exact anchor and handle coordinates can also be typed numerically.
- Add/delete points, mirror, undo/redo, seam allowance editing and redraft are available.
- Apply Pattern commits the edited pattern state to the project workflow.
- Assemble → 3D returns to the garment workspace and starts the existing simulation path.

This is a visual CAD foundation. It does not yet constitute a certified industrial patternmaking kernel or validated production block.
